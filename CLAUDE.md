# Tourist Trophy decompilation — notes for Claude

Start with the project skill `tt-decomp` (.claude/skills/tt-decomp/SKILL.md): the judge, the
compilers and their markers, the source layout, the tools by purpose, the rules for agents and
which knowledge file answers which question. Read TOOLS.md and knowledge/ only for the part you
need. The tools are shared with the Gran Turismo 4 project (github.com/gustavocanepa/gt4-decomp, cloned next to this repository as ../GT4), whose sources are
the first place to look for a function both games have.
